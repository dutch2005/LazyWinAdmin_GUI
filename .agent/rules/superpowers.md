# Superpowers Workflow Protocol

## When to use this skill
- Before implementing non-trivial features
- Before refactors with unclear scope
- Before debugging complex issues
- Before designing an automation workflow

## Enforcement
You must use the following commands to navigate the task. Do not write code until a plan is verified.
1. /superpowers-brainstorm - Explore ideas with Q&A
2. /superpowers-write-plan - Create a detailed plan
3. /superpowers-execute-plan - Build code step-by-step
4. /superpowers-review - Check code quality before finishing
